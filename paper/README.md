# Silicon Atlas paper

[`silicon-atlas.pdf`](silicon-atlas.pdf) describes the platform's educational design, software
architecture, physical models and numerical methods, and reports how each physics kernel was
verified.

Every number, table and plot in the paper is generated from the code in this repository.

| Step | Command | What it does |
| --- | --- | --- |
| 1 | `pnpm paper:data` | Runs the same TypeScript kernels the browser uses and writes `data/*.json` |
| 2 | `pnpm paper:figures` | Recomputes every reference result independently with NumPy and SciPy, writes `figures/*` and the error summary `data/summary.json` |
| 3 | `pnpm paper:pdf` | Builds `main.tex` with LaTeX and copies the result to `silicon-atlas.pdf` |

Step 2 needs Python 3 with `numpy`, `scipy` and `matplotlib` (see `requirements.txt`). Step 3
needs a TeX distribution with `latexmk`; `IEEEtran.cls` and `IEEEtran.bst` are included.

The screenshots `figures/fig_map.png` and `figures/fig_ui.png` were captured from the running app
in the light theme and are not regenerated by these scripts.

## Files

```

refs.bib              references cited in the paper
references.bib        working bibliography with verification notes (see docs/literature-review.md)
scripts/export-data.ts
scripts/make_figures.py
data/                 kernel output and the verification summary
figures/              generated figures and the two app screenshots
```
